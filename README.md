# PawCKet FurTal

A pet adoption and welfare application for Baguio City Animal Welfare.

## Features

- Pet adoption
- Lost & found pet reporting
- Veterinary clinic directory
- Donation support

## APK

The latest APK can be found in `app/build/outputs/apk/debug/app-debug.apk` after building the project.

## Building

1. Open the project in Android Studio
2. Click Build → Rebuild Project
3. Click Build → Build Bundle(s) / APK(s) → Build APK(s)
